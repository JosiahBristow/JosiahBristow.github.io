Markdown 简明教程

🕐 2026-07-26 18:06 👁️ 8 💬 0 👍 0

Markdown 是一种轻量级标记语言，让你用纯文本格式就能写出结构清晰、排版美观的文档。

1. 标题

使用 # 符号，数量表示级别。

源码：

# 一级标题
## 二级标题
### 三级标题
#### 四级标题
##### 五级标题
###### 六级标题

预览：

一级标题

二级标题

三级标题

四级标题

五级标题
六级标题

2. 文本样式

源码：

**粗体**  *斜体*  ***粗斜体***  ~~删除线~~  `行内代码`

预览：
粗体 斜体 粗斜体 删除线 行内代码

3. 列表

无序列表

源码：

- 苹果
- 香蕉
  - 子项（缩进）
- 橙子

预览：

  • 苹果
  • 香蕉
    • 子项（缩进）
  • 橙子

有序列表

源码：

1. 第一项
2. 第二项
   1. 子项1
   2. 子项2
3. 第三项

预览：

  1. 第一项
  2. 第二项
    1. 子项1
    2. 子项2
  3. 第三项

任务列表

源码：

- [x] 已完成
- [ ] 未完成

预览：

4. 链接和图片

链接源码：

[百度](https://www.baidu.com)

链接预览：
百度

图片源码：

![占位图](https://via.placeholder.com/150)

图片预览：

引用式链接源码：

[百度][1]
[1]: https://www.baidu.com

预览效果同普通链接。

5. 引用

源码：

> 这是一段引用。
> > 嵌套引用。

预览：

这是一段引用。

嵌套引用。

6. 代码块

源码：

```python
print("Hello, World!")
```

预览：

print("Hello, World!")

（缩进 4 个空格或 1 个 Tab 同样有效）

7. 表格

源码：

| 左对齐 | 居中 | 右对齐 |
|:-------|:----:|-------:|
| 内容1  | 内容2| 内容3  |
| 内容4  | 内容5| 内容6  |

预览：

左对齐 居中 右对齐
内容1 内容2 内容3
内容4 内容5 内容6

8. 分隔线

源码：

---
***
___

预览：

___（实际渲染效果相同，均为一条水平线）

9. 转义字符

用反斜杠 \ 让特殊字符显示为普通字符。

源码：

\# 这不是标题，\*不是斜体\*

预览：
# 这不是标题，*不是斜体*
（实际渲染会显示 # 和 * 原样，不会被解析为标记）

10. 段落和换行

  • 段落间用空行分隔（预览时可见自然间距）。
  • 换行：行末加两个空格 或使用 <br>。

源码示例：

第一段（后面空一行）

第二段
行末加两个空格  
这是新行

预览：
第一段（后面空一行）

第二段
行末加两个空格
这是新行

非常好！在基础语法之上，许多主流 Markdown 编辑器（如 Typora、Obsidian）和平台（GitHub、GitLab）都支持扩展语法。这部分能让你的文档功能更强大，从“记事本”升级为“专业写作工具”。

以下是最常用、最实用的扩展语法，同样附带 源码 与 预览。

11 脚注（Footnote）

用于在页面底部添加注释，适合解释术语或标注引用。

源码：

这是一个带脚注的句子[^1]。

[^1]: 这是脚注的具体内容，通常显示在页面底部。

预览：
这是一个带脚注的句子[1]。

12 高亮、上标与下标

  • 高亮：==文字==（Typora、Obsidian 支持）
  • 上标：^上标^
  • 下标：~下标~

源码：

这行文字有 ==高亮标记==。

化学式：H~2~O  
数学式：E = mc^2^

预览：
这行文字有 高亮标记。

化学式：H2O
数学式：E = mc2

13 折叠块（Details / Summary）

利用原生 HTML 标签实现可折叠内容，非常适合放答案、附录或长代码。

源码：

<details>
  <summary>点击展开查看答案</summary>
  这里是隐藏的具体内容，点击上方标题即可展开或收起。
</details>

预览：

点击展开查看答案 这里是隐藏的具体内容，点击上方标题即可展开或收起。

14 GitHub 警告（Alerts / Admonitions）

GitHub 独有的提示框语法，用于突出显示注意、提示、警告等信息。

源码：

> [!NOTE]
> 这是一个普通的提示信息。

> [!TIP]
> 这是一个实用的小技巧。

> [!IMPORTANT]
> 这是至关重要的核心信息。

> [!WARNING]
> 这是需要警惕的警告内容。

> [!CAUTION]
> 这是可能造成负面影响的风险提示。

预览（GitHub 风格）：

[!NOTE]
这是一个普通的提示信息。

[!TIP]
这是一个实用的小技巧。

[!IMPORTANT]
这是至关重要的核心信息。

[!WARNING]
这是需要警惕的警告内容。

[!CAUTION]
这是可能造成负面影响的风险提示。

15 Mermaid 图表（流程图 / 时序图）

在支持 Mermaid 的编辑器（Typora、Obsidian、GitHub）中，可以直接用代码画图。

源码（流程图）：

```mermaid
graph TD
    A[开始] --> B{是否有错误?}
    B -- 是 --> C[报错退出]
    B -- 否 --> D[执行成功]
```

预览（在支持环境下渲染为矢量图）：
（此处无法动态渲染，但在 Typora/GitHub 中会显示为如下流程图）

  • 开始 → 是否有错误? →（是）报错退出 /（否）执行成功

源码（时序图）：

```mermaid
sequenceDiagram
    用户->>系统: 点击登录
    系统-->>用户: 返回验证码
```

16 数学公式（LaTeX）

使用 $ 包裹行内公式，$$ 包裹块级公式（需编辑器开启 MathJax 支持）。

源码：

行内公式：$E = mc^2$

块级公式：
$$
\int_{-\infty}^{\infty} e^{-x^2} dx = \sqrt{\pi}
$$

预览：
行内公式：\(E = mc^2\)

块级公式：

\[\int_{-\infty}^{\infty} e^{-x^2} dx = \sqrt{\pi} \]

17 自动 URL 链接

直接写网址或邮箱，自动变成可点击链接（GFM 特性）。

源码：

https://github.com
user@example.com

预览：
https://github.com
user@example.com

18 Emoji 表情（GFM）

输入 :emoji名称: 即可显示表情（GitHub、Typora 支持）。

源码：

:smile: :rocket: :heart: :+1:

预览：
😄 🚀 ❤️ 👍

19 删除线（已在基础部分涵盖，此处仅补充）

~~删除线~~ → 删除线

20 HTML 原生标签

Markdown 兼容大部分 HTML 标签，可实现更精细的排版。

源码：

<p style="color: red; text-align: center;">这是一段红色的居中文字</p>
<kbd>Ctrl</kbd> + <kbd>C</kbd>

预览：

这是一段红色的居中文字

Ctrl + C

最后提醒：兼容性

并非所有平台都支持全部扩展语法，建议根据发布平台选择：

  • GitHub：支持 GFM（任务列表、表格、警告、Mermaid、自动链接）。
  • Typora / Obsidian：支持高亮、上下标、数学公式、Mermaid。
  • 通用兼容：基础语法 + HTML 标签几乎在所有平台都能用。

附：如何预览 Markdown

  • 本地编辑器：Typora、VS Code（安装 Markdown 插件）、Obsidian 等支持实时预览。
  • 在线工具：Dillinger、StackEdit 或 GitHub/Gitee 的 README 预览。
  • 命令行：使用 pandoc、marked 等转换输出。
  • 浏览器插件：使用Markdown Reader、Markdown Viewer等插件在浏览器预览
