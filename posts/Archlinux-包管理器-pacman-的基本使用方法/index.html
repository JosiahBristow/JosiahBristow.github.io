Archlinux 包管理器 pacman 的基本使用方法

🕐 2026-04-18 12:56 👁️ 74 💬 0 👍 0

Pacman 简介

以下是 Arch Wiki 的介绍：

pacman 包管理器是 Arch Linux 的主要特色之一。它将简单的二进制包格式与易于使用的 Arch 构建系统相结合。pacman 的目标是能够轻松管理软件包，无论是来自 官方仓库还是用户自己的构建。

pacman 通过与主服务器同步软件包列表来保持系统更新。这种服务器/客户端模型还允许用户通过一个简单的命令下载/安装软件包，并包含所有必需的依赖项。

pacman 是用 C 语言编写的，并使用 bsdtar tar 格式进行打包。

2. 基础用法（每天都要用）

2.1 安装软件包

# 从仓库安装（支持正则，例如 pacman -S '^kde-'）
sudo pacman -S 包名

# 安装本地包（.pkg.tar.zst）
sudo pacman -U 本地包文件.pkg.tar.zst

批量选择技巧：
当安装软件包组时，会弹出选择提示：

Enter a selection (default=all): 1-5 8
  • 1-5 8 → 安装第1到第5个以及第8个
  • ^2-4 → 除了第2到第4个，其他都装

2.2 删除软件包

sudo pacman -R 包名          # 删包，保留依赖（不推荐）
sudo pacman -Rs 包名         # 删包+无用依赖（常用）
sudo pacman -Rns 包名        # 删包+依赖+配置文件（彻底清除）

2.3 升级整个系统

sudo pacman -Syu

2.4 搜索

pacman -Ss 关键词     # 远程仓库搜索
pacman -Qs 关键词     # 已安装包搜索

2.5 清理缓存

缓存目录：/var/cache/pacman/pkg/

sudo pacman -Sc      # 删除未安装的包（安全）
sudo pacman -Scc     # 删除所有缓存包（⚠️ 将无法降级，慎用）

3. 进阶维护技巧

3.1 软件降级（使用 downgrade）

sudo pacman -S downgrade          # 从 AUR 或 community 安装
sudo downgrade 包名               # 从列表中选择旧版本号安装

3.2 解除数据库锁

报错 could not lock database 时：

sudo rm /var/lib/pacman/db.lck
sudo pacman -Syu

3.3 转换并安装 .deb 包（以 debtap 为例）

# 安装 debtap（需要 AUR 助手，见第4节）
yay -S debtap

sudo debtap -u                     # 更新转换数据库
debtap 你的软件.deb                # 生成 .pkg.tar.zst
sudo pacman -U 生成的包.pkg.tar.zst

注意：转换后的包可能缺少依赖，建议用 pacman -Qi 包名 检查。

4. 更近一步：AUR 助手

pacman 无法直接安装 AUR 中的软件，需要助手。主流的有 yay和 paru。
他们但使用方法和 pacman 几乎完全一样。

特性 yay paru
开发语言 Go Rust
特点 成熟稳定，功能完整 现代、速度快、彩色输出
搜索 按相关性排序 支持正则，分仓库显示
安全性 稳健 需注意 -Sy 等操作（有争议）
安装方式 通过 AUR 克隆构建 通过 AUR 克隆构建

安装方法：

  1. 使用 pacman 安装
sudo pacman -S yay paru
  1. 手动编译安装
# 先安装 base-devel 和 git
sudo pacman -S --needed base-devel git

# 安装 yay
git clone https://aur.archlinux.org/yay.git
cd yay
makepkg -si

# 安装 paru
git clone https://aur.archlinux.org/paru.git
cd paru
makepkg -si

5. 常见问题速查

问题 解决方案
提示 “failed to commit transaction (conflicting files)” 用 pacman -Qo 文件路径 查看冲突文件属于哪个包，手动处理
升级时卡住很久 检查网络和镜像源：sudo pacman -Syy 强制刷新
想查看某个包被哪个依赖引入 pactree -r 包名

6. 总结

  • 日常使用：-Syu、-S、-Rs、-Sc 四者足够。
  • 遇到锁或依赖问题：先删 db.lck，或用 downgrade。
  • AUR 助手推荐 yay（新手友好）或 paru（性能控）。
  • 转换 deb 是最后手段，优先找 AUR 或 Flatpak。

本文内容基于 Arch Linux 2026.04 环境，如有变动以官方 wiki 为准。
