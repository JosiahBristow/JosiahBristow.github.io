📚 书架

读过和正在读的书

算法导论（原书第3版）
Thomas H. Cormen / Charles E. Leiserson / Ronald L. Rivest / Clifford Stein
⭐ 9.3
计算机科学经典教材，全面介绍算法设计与分析。涵盖排序、图算法、动态规划、贪心算法等核心主题，是算法学习的权威参考书。
深入理解计算机系统（第3版）
Randal E. Bryant / David R. O'Hallaron
⭐ 9.8
CSAPP 被誉为计算机系统领域的神作。从硬件到软件，从汇编到内存管理，帮助程序员真正理解计算机的工作原理。
C Primer Plus 中文版（第6版 2020版）
Stephen Prata
⭐ 9.6
C语言入门经典，内容全面系统。从基础语法到指针、数据结构、文件操作，循序渐进，适合初学者系统学习 C 语言。
C++ Primer Plus 中文版（第六版）
Stephen Prata
⭐ 8.5
C++ 编程全面教程，从基础到面向对象编程、STL、异常处理等。适合有 C 语言基础的读者进阶学习 C++。
30天自制操作系统
川合秀实
⭐ 8.7
手把手带你从零编写一个操作系统。从引导程序、中断处理到内存管理、多任务，通过实践深入理解操作系统的核心原理。
鸟哥的Linux私房菜 基础学习篇 第四版
鸟哥
⭐ 9.1
Linux 入门经典。从 Linux 安装、命令行操作到 Shell 脚本、网络管理，内容贴近实战，是 Linux 初学者和进阶者不可多得的好书。
